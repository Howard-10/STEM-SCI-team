# Contributing

Phase 1 changes must preserve Controller-only stage transitions, reference-only state storage, and the project invariants documented in `docs/STEM_SCI_Complete_Project_Plan.md`.

Python backend changes belong under `backend/`. Frontend, contracts, data, and infrastructure boundaries must remain independent of backend business implementation until their phase scope is approved.

Do not add business implementations, external providers, or new dependencies without an approved phase scope.
