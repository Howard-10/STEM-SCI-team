# ResearchPilot 演示操作手册

> 按步骤操作即可。每个步骤包含：做什么、在哪做、输入什么、期望结果。

---

## 第一步：启动项目（录之前做好）

打开两个终端窗口：

**终端 1 — 前端：**
```bash
cd d:\科研增效
npm.cmd run dev
```
看到 `http://localhost:5173` 就绪。

**终端 2 — 后端（如果要演示 HTTP 真实模式才需要）：**
```bash
cd d:\科研增效\server
npm.cmd run dev
```
看到 `listening on http://localhost:3001` 就绪。

> 建议先用 mock 模式录，稳定不出错。mock 模式不需要启动后端。

---

## 第二步：录前数据准备（录之前花 3 分钟做好）

打开浏览器，访问 `http://localhost:5173`。

项目首次打开会**自动注入 2 个种子项目**，其中"科研阅读与写作助手设计"已经预置了 1 篇论文和 1 个 Idea。

但演示对比功能需要**至少 2 篇论文**，所以先给它加一篇。

### 2.1 加第二篇论文

1. 首页 → 点击「进入工作台」→ 看到两个项目卡片
2. 点击「科研阅读与写作助手设计」→ 进入项目仪表盘
3. 左侧导航栏 → 点击「文献精读」
4. 在输入区填：

```
论文标题：
Retrieval-Augmented Generation for Scientific Literature Review: A Survey

论文摘要：
This survey systematically reviews RAG-based approaches for scientific literature understanding, covering retrieval strategies, chunking methods, reranking techniques, and evaluation frameworks. The authors propose a taxonomy of RAG architectures for scientific domains and identify key challenges including evidence grounding, hallucination reduction, and cross-disciplinary generalization.

关键词：
retrieval augmented generation, scientific literature, survey, evidence grounding
```

5. 点击「生成精读卡片」→ 等待卡片出现
6. 点击「保存到项目」

> 现在项目里有 2 篇论文了，对比功能可用。

### 2.2 生成并保存领域报告

1. 左侧导航栏 → 点击「领域快速入门」
2. 输入区填：

```
研究方向：
AI 辅助科研工作流优化

具体需求：
请帮我梳理这个领域的研究背景、核心概念、主流方法、常用数据集、当前挑战和可能的研究切入点。
```

3. 点击「生成报告」→ 等待四组卡片出现
4. 点击「保存到项目」

### 2.3 保存一条实验分析记录

1. 左侧导航栏 → 点击「实验结果分析」
2. 输入区填：

```
实验名称：
Ablation Study on RAG Retrieval Strategies for Scientific Text

实验结果文本框：
Baseline (BM25): ROUGE-L 0.32, Faithfulness 0.71
+ Dense Retrieval (E5): ROUGE-L 0.38, Faithfulness 0.76
+ Reranking (Cross-Encoder): ROUGE-L 0.41, Faithfulness 0.80
+ Query Expansion: ROUGE-L 0.43, Faithfulness 0.82

异常现象：Query Expansion 在跨学科文献上 Faithfulness 反而下降到 0.69
```

3. 点击「生成分析」→ 等待分析结果出现
4. 点击「保存到项目」

### 2.4 保存一条写作草稿

1. 左侧导航栏 → 点击「写作输出」
2. 写作类型选「论文 Introduction」
3. 用户补充要求填：

```
请围绕 RAG 在科研文献理解中的应用展开，先讲科研人员面临的信息过载问题，再引出 RAG 作为解决方案，最后点出当前方法在证据可追踪性和结构化输出方面的不足。
```

4. 点击「生成内容」→ 等待输出出现
5. 点击「保存到项目」

> 数据准备完成。此时项目里应有：领域报告 1 份、论文 2 篇、实验记录 1 条、写作草稿 1 条。检查一下项目仪表盘的四个指标数字是否变成 2/3/1/1 左右。

## 第三步：正式演示路线（录制时按此操作）

### Step 1 — 首页（讲稿第 1 页，5 秒）

展示首页。

鼠标指向「科研闭环流程」区域的 8 步卡片，停留 3 秒让观众看清流程。

**口播：** "这是 ResearchPilot，一个覆盖科研全流程的 AI 工作台。"

---

### Step 2 — 项目列表（讲稿第 5 页，10 秒）

点击「进入工作台」→ 展示两个项目卡片。

鼠标在「科研阅读与写作助手设计」卡片上悬停。

**口播：** "系统以项目为中心组织所有研究数据，每个项目绑定自己的论文、实验和写作记录。"

点击进入「科研阅读与写作助手设计」→ 进入仪表盘。

---

### Step 3 — 仪表盘（讲稿第 5 页，20 秒）

展示仪表盘的四个指标卡片：文献数量、研究想法数量、实验记录数量、写作草稿数量。

鼠标逐个指向四个数字。

**口播：** "仪表盘汇总了项目当前的所有数据——论文、想法、实验、草稿。下面还会自动生成下一步建议。"

向下滚动，展示「当前项目下一步建议」区域。

**口播：** "系统根据项目当前状态，自动建议你应该优先做什么。"

---

### Step 4 — 领域快速入门（讲稿第 8 页，25 秒）

左侧导航栏 → 点击「领域快速入门」。

展示已经生成好的四组报告卡片。

鼠标指向每组卡片，逐一过：
- 基础认知组（背景+概念）
- 研究版图组（任务+方法+挑战）
- 数据与评估组（数据集+指标）
- 切入与路线组（方向+阅读路线）

**口播：** "输入研究方向后，AI 自动生成四组结构化报告——从背景概念到研究版图，从常用数据集到建议阅读路线。每一步都绑定到项目，不会丢失。"

---

### Step 5 — 文献精读（讲稿第 9 页上半，20 秒）

左侧导航栏 → 点击「文献精读」。

向下滚动到「已保存论文列表」，展示 2 篇已保存论文。

鼠标指向其中一篇的「导出 Markdown」按钮。

**口播：** "每篇论文都被解析成 9 维精读卡片——背景、动机、方法、创新点、实验设计、局限、启发等等。系统还会自动判断这篇论文是否适合做 Baseline。支持导出 Markdown，直接放进你的文献笔记。"

---

### Step 6 — 多论文对比（讲稿第 9 页下半，40 秒）★ 最关键的演示环节

左侧导航栏 → 点击「多论文对比与研究空白」。

**勾选操作：**
- 勾选第一行论文的复选框（RAG Survey）
- 勾选第二行论文的复选框（RAG Scientific Reading Assistant）

页面顶部提示变为"当前已选择 2 篇论文"。

点击「生成对比表」→ 等待生成。

**生成结果展示：**

先展示上方的「对比表」——从上到下滚动，让观众看到 8 个维度的横向排列。

**口播：** "勾选两篇已保存论文，一键生成逐维对比表——Motivation、方法、创新点、数据集、评价指标全部横向对齐。你一眼就能看出论文之间的异同。"

向下滚动到「研究空白分析」区域，展示：
- 共性问题
- 未解决问题
- 数据缺口
- 方法缺口
- 可转化研究问题
- Idea 卡片（展示三维评分）

**口播：** "更关键的是研究空白分析——系统找出了这几篇论文的共性问题、数据和方法缺口，并自动生成了可执行的研究 Idea，附带新颖性、可行性、工作量三个维度的评分。这是帮你从读论文到找到自己选题的关键一步。"

---

### Step 7 — 实验分析（讲稿第 10 页下半，20 秒）

左侧导航栏 → 点击「实验结果分析」。

向下滚动到「历史实验分析列表」，展示已保存的实验记录。

点击「查看详情」→ 弹窗展示完整分析（停留 5 秒后关闭）。

**口播：** "输入实验名称和原始结果文本，AI 自动给出趋势分析、异常值标注、补充实验建议，还会生成可直接运行的 matplotlib 代码片段。复制到 Jupyter Notebook 就能出图。"

---

### Step 8 — 写作输出（讲稿第 11 页上半，20 秒）

左侧导航栏 → 点击「写作输出」。

向下滚动到「历史写作草稿列表」，展示已保存的草稿。

点击「查看详情」→ 弹窗展示论文段落 + PPT 大纲 + 讲解稿。

**口播：** "写作模块支持六种类型——Introduction、Related Work、Method、Experiment、PPT 大纲、答辩讲稿。一次生成三样东西：论文段落、PPT 大纲和讲解稿。你做汇报的时候直接就能用。"

---

### Step 9 — 成果记录（讲稿第 11 页下半，20 秒）

左侧导航栏 → 点击「项目成果记录」。

展示五组分类型聚合的成果记录——领域报告、论文卡片、实验记录、写作草稿、研究 Idea。

鼠标指向「导出 Markdown」按钮。

**口播：** "所有产出都汇总在成果记录页面——按类型聚合、支持查看详情、一键导出 Markdown、随时删除。你的每一分努力都被系统记住，不会丢失。"

---

### Step 10 — 导出 Markdown (Bonus，10 秒)

回到仪表盘。

点击「导出项目 Markdown」按钮 → 浏览器自动下载一个 .md 文件。

打开下载文件夹，展示文件。

**口播：** "整个项目的完整知识资产，一键导出为一个 Markdown 文件——包含领域报告、论文精读、实验分析、写作草稿和下一步建议。"

---

## 常见问题

**Q: 对比功能提示"至少需要 2 篇论文"？**
A: 说明数据准备没做好。回到文献精读页，确认「已保存论文列表」至少有 2 篇。

**Q: Mock 模式生成的结果不够好？**
A: Mock 是规则引擎，输出固定。如果想展示更好的效果，启动后端，切到 http 模式，录之前把数据重新生成一遍。

**Q: 演示中途不小心关掉了浏览器？**
A: 数据存在 localStorage 里，重新打开浏览器访问 localhost:5173 就行，数据不丢。

**Q: 忘记怎么操作某个模块了？**
A: 每个页面顶部都有标题和说明文字，直接看屏幕就行。
