## 二、文献整理与解读模块

### 2.1 单论文深度解读

**输入**: PDF 文件（支持上传 + 拖拽）

**PDF 解析**: 三策略管线，自动选最优
- 策略1: PyMuPDF + pymupdf_layout（保留连字和空格）
- 策略2: PyMuPDF dict 模式 + 位置坐标排序（处理双栏排版）
- 策略3: pdfplumber（复杂表格场景最优）
- 评分系统（0.0-1.0）：自动选择最高分策略

**文本质量预检**:
- 提取字符数检测（<100 = 空 / <500 = 差）
- 可读字符比例检测（字母/数字/标点占比）
- `good` / `acceptable` / `poor` / `empty` 四级评级
- 支持「强制读取」模式（忽略质量检查，适用于扫描版 PDF）

**五维度分析**（全文一次性 LLM 调用）:
1. **论文概览**: 研究领域、子方向、目标会议/年份推测、一句话核心思想
2. **动机与背景**: 研究问题陈述、现有方法不足（3-5点）、本文核心洞察
3. **方法论深度**: 问题数学形式化、模型架构详解（逐组件描述）、算法流程、关键创新点列表、核心公式解读（名称/公式/含义）
4. **实验全面分析**: 数据集列表（名称+用途+规模）、评估指标、主实验结果解读（含表格）、消融实验分析、Baseline 对比分析、效率分析（参数量/FLOPs/推理时间）
5. **深度评价**: 方法论优势、方法论局限、实验说服力评估、可复现性评估、与已有工作关系、影响力评估、潜在后续方向、创新等级评定

**元数据提取**: 标题、作者、摘要、章节结构、图表数量、参考文献

**输出**: 5 个 Tab 页的结构化中文报告

### 2.2 多论文综述对比

**输入**: 多个 PDF 文件

**流程**:
1. 并行分析所有论文（ThreadPoolExecutor，最多 4 并发）
2. 每篇论文独立调用单论文深度解读
3. 生成每篇的质量评分和状态（success/partial/failed）

**研究方向对比**（LLM 智能判断）:
- 自动提取每篇论文的研究领域和子方向
- LLM 进行语义相似度判断（0-100 分）
- 三档判定：≥70分 方向一致 / 40-69分 部分相关 / <40分 差异较大
- 差异较大时提醒用户

**模块对模块综述**（一次 LLM 调用完成）:
- 论文分类聚类
- 8+ 行对比表格（研究问题/方法/架构/创新/数据集/指标/优势/局限 × N 篇）
- 3000-5000 字综述报告（现状→方法论对比→实验对比→评价→方向）
- 论文关系图谱（引用/改进/对比关系）
- 实验数据深度对比分析

**并行优化**: N 篇论文耗时 ≈ max(单篇耗时)，而非 N×单篇耗时

## 三、模型融合模块

### 3.1 代码智能分块

**输入**: 项目文件夹路径 或 上传 `.zip` 代码包

**AST 静态分析**:
- 自动遍历项目所有 `.py` 文件
- 识别 PyTorch 组件：`nn.Module` 子类、`Dataset`、`DataLoader`、Loss Function、Optimizer、训练/验证循环
- 提取 `forward` 方法作为前向传播独立块
- 按函数名自动推断类别（含 `augment`/`preprocess` → 数据增强；含 `train_epoch`/`training_step` → 训练循环）

**LLM 语义增强**:
- 对每个代码块修正分类错误
- 生成一句话中文描述

**6 类顶层分类**（LLM 读取块内容后归类）:
- 📐 参数与配置（超参数、模型维度、argparse）
- 🏗️ 模型架构（nn.Module、forward、attention 等）
- 📊 数据处理（Dataset、DataLoader、预处理/增强）
- 🔄 训练与优化（训练循环、优化器、损失函数、调度器）
- 📈 评估与日志（验证/测试、指标、checkpoint）
- 🔧 工具与入口（main 函数、可视化、文件 I/O）

**支持三种输入方式**: 上传 zip / 本地路径 / 历史缓存

**缓存管理**: 分析结果自动缓存为 JSON，支持删除和复用

### 3.2 代码块 AI 解读

**功能**: 每个分块侧面设「💬 AI 解读」按钮

**解读内容**:
1. 代码块的具体含义和用途——做了什么、为什么这样设计
2. 与上一个代码块的连接关系——数据如何流入/流出、依赖关系

**实现**: 按钮点击后自动发送当前块源码 + 上一个块上下文到侧边栏 AI Agent

### 3.3 智能模块迁移

**两种路径**:
- **路径一: 从历史分块选择**——在已缓存的分析结果中按类别筛选，选择模块迁移
- **路径二: 双项目实时对比**——输入源项目+目标项目路径，双栏展示

**布局**: 左侧（源模块/待迁移）+ 右侧（目标模型/有序分块）

**目标模型有序分块**:
- 仅提取数据处理、模型架构、损失函数三类
- 按 `forward` 顺序展开（`file_path` + `start_line` 排序）
- 便于确定模块插入位置

**操作流程**:
1. 点击源模块 → 选中（变蓝🔵）
2. 在目标模型中点击「↓ 插入此处」→ 定位插入位置（变绿🟢）
3. 点击「🔀 AI 自动对齐」→ 生成迁移代码
4. 预览对齐结果 + 风险评估（梯度风险/维度风险/稳定性风险）
5. 点击「💾 保存」→ 写入文件（原文件自动备份为 `.bak`）
6. 不点保存 = 不修改

**自动维度对齐**:
- 检测 `in_channels` / `out_channels` 差异
- 自动生成 `nn.Linear` / `nn.Conv2d` 适配层
- LLM 评估计算图连续性和梯度中断风险

**AI 助手联动**: 「🤖 AI 推荐迁移方案」按钮，Agent 读取双仓库架构后推荐

## 四、数据处理模块

### 4.1 数据集自动适配

**输入**: 数据集路径（文件或文件夹）+ 可选模型代码（上传 zip 或手动粘贴）

**数据集解读**:
- 自动检测格式：`image_folder` / `csv` / `json` / `npy` / `hdf5`
- 采样分析：样本数量、特征维度（图片→宽高通道；CSV→列数）、标签类型（分类/回归）、类别数
- LLM 增强描述

**模型代码自动提取**:
- 上传模型项目 zip → 自动扫描
- 只提取数据相关模块（Dataset/DataLoader/模型架构/Forward）
- 拼接为上下文供 DataLoader 生成

**DataLoader 生成**:
- 自定义 Dataset 类（`__init__` / `__len__` / `__getitem__`）
- 数据变换（transforms，匹配模型输入维度）
- 训练/验证/测试集划分
- 完整可运行代码，支持下载

### 4.2 包装化数据增强与攻击

**20 种操作全覆盖**:

| 类别 | 操作 | 实现方式 |
|------|------|---------|
| 几何变换 | 随机裁剪/翻转/旋转/缩放裁剪/仿射变换 | torchvision transforms |
| 色彩变换 | 颜色抖动/亮度/对比度/饱和度 | torchvision transforms |
| 模糊化 | 高斯模糊/中值模糊(PIL)/运动模糊(自定义conv内核) | torchvision + PIL |
| 噪声注入 | 高斯噪声(torch.randn)/椒盐噪声(numpy mask) | 自定义实现 |
| 高级增强 | CutOut(随机矩形mask)/MixUp(颜色混合)/CutMix(区域替换)/RandAugment | 自定义 + torchvision |
| 数据攻击 | FGSM(符号梯度噪声)/PGD(多步迭代噪声) | 自定义实现 |

**四步工作流**:
1. **选择操作**: 分类折叠展示 + 每组支持「全选」
2. **单图测试**: 上传图片 → 实时预览原图 vs 增强后（base64 渲染）
3. **批量处理**: 指定文件夹 → 按操作名称分目录保存 → 结果统计
4. **自定义增强**: AI 交互描述需求 或 生成可集成代码 → 下载 `.py`

**图片预处理**: 自动缩放到 256×256 避免小图 crop 报错

**AI 助手联动**: 根据数据形式推荐增强方案

## 五、实验模块

### 5.1 可视化工作自动化

**图表类型推荐**:
- 从文献整理模块自动读取已分析论文内容
- 用户勾选引用论文 → AI 基于论文的方法/数据集/指标推荐图表类型
- 支持上传参考样例图片
- 支持手动填写研究上下文

**三种数据输入**:
- 📝 文本描述（如"ResNet 78.5%, ViT 82.1%"）
- 📁 上传 CSV/JSON/TXT 文件
- 📋 直接粘贴数据

**迭代生成 + 自动评分修缮**:
- AI 生成 matplotlib 代码 → subprocess 执行出图
- 5 维度评分系统（每维度 0-20 分，总分 100）:
  1. 数据展示清晰度
  2. 标签与标题
  3. 配色与美观（Morandi 学术配色）
  4. 科研规范性
  5. 整体完成度
- 评分 < 90 → AI 根据反馈修缮代码 → 重新出图 → 循环（最多 5 轮）
- 评分 ≥ 90 → 输出最终图表 + Python 代码

**输出**: 迭代历史表格 + 最终图片 + 可下载绘图脚本

### 5.2 消融实验智能包装化

**输入**: 上传项目 zip 或输入本地路径

**智能识别**:
- 读取项目全部代码
- LLM 按两个条件筛选可消融模块:
  1. 拆卸后不影响全局（独立可插拔）
  2. 作为模型的创新点（验证其重要性）
- 列出每个模块的所有出现位置（如 Block1/Block2/Block3 中都出现了该模块）

**用户选择**: 勾选消融目标，`⭐` 标注推荐消融的模块

**代码修改**:
- 移除所有出现位置（不遗漏任何一处）
- 自动计算断开处的维度差异
- 添加 `nn.Linear` / `nn.Conv2d` 适配层
- 确保生成代码可运行

**输出**: 修改摘要 + 维度对齐列表 + 警告信息 + 完整修改后代码

**保存**: 原文件自动备份为 `.bak`，确认后写入

### 5.3 超参数智能调优

**三种输入方式**: 上传 zip / 本地路径 / 直接粘贴代码

**全量超参数识别**:
- LLM 扫描代码中所有超参数
- 显式参数：lr / batch_size / epochs / weight_decay / dropout / hidden_dim 等
- 隐式参数：优化器选择、损失函数参数、架构参数（层数/通道数）
- 每个参数标注：当前值、类型、定义位置、建议范围、影响程度（high/medium/low）

**可编辑面板**: 每个参数一个文本框，直接修改值

**训练过程诊断**:
- 用户描述训练过程（loss 曲线变化、准确率波动等）
- AI 诊断问题（过拟合/欠拟合/学习率过大/正则化不足）
- 给出具体调参建议（含优先级 🔴高/🟡中/🟢低）
- 推荐训练技巧

**配置代码生成**: 修改后的参数 → 生成可替换原配置的 Python 代码块

### 5.4 实验结果记录

**自动存储**: SQLite 数据库记录每次实验
- 实验名称、模型名称、超参数（JSON）
- 训练指标、测试指标（JSON）
- Epoch 级别日志（train_loss / val_loss / train_acc / val_acc / lr）
- 模型权重路径

**查询功能**:
- 关键词搜索筛选
- 多实验对比分析
- Epoch 折线图可视化
- 导出 CSV

## 六、AI Agent 智能体系统

### 6.1 核心架构

**Claude 式编排器**:
- Think → Act → Observe → Reflect 循环
- 最多 8 轮工具调用迭代
- 多轮会话记忆（session_id 持久化）
- 研究上下文管理

**底层**: DeepSeek V4 的 Function Calling（OpenAI 兼容接口）

### 6.2 19 个标准化工具

**系统工具（6 个）**: `read_file` / `write_file` / `edit_file` / `glob_files` / `grep_files` / `bash_exec`

**科研工具（13 个）**:
- `analyze_paper` / `review_papers`（文献）
- `chunk_code` / `recommend_modules` / `migrate_module`（融合）
- `inspect_dataset` / `generate_dataloader` / `generate_augmentation`（数据）
- `generate_visualization` / `plan_ablation` / `identify_hyperparams` / `generate_scheduler` / `list_experiments`（实验）

### 6.3 4 项领域技能（Skill 系统）

| 技能 | 触发词 | 推荐工具 | 核心 SOP |
|------|--------|---------|---------|
| literature-review | 解读论文/综述/对比 | analyze_paper, review_papers | 确认路径→调用工具→结构化输出 |
| model-fusion | 代码分块/模块迁移 | chunk_code, migrate_module | 分析项目→识别模块→评估风险 |
| data-processing | 数据集/DataLoader/增强 | inspect_dataset, generate_augmentation | 解读数据→推荐操作→生成代码 |
| experiment-management | 可视化/消融/调参 | plan_ablation, identify_hyperparams | 理解需求→规划方案→生成执行 |

**技能工作方式**: 触发词匹配 → SOP 注入 System Prompt → 工具过滤 → 专业输出

### 6.4 权限控制系统

| 级别 | 说明 | 示例 |
|------|------|------|
| read_only | 自动允许 | glob_files, grep_files, read_file |
| write_safe | 项目内自动允许 | write_file, edit_file |
| write_confirm | 需确认 | 项目外写入 |
| dangerous | 拦截警告 | rm -rf, sudo, curl\|sh, git push --force |

**API 层安全**: 路径穿越防护、ZIP 攻击拦截、文件类型校验

### 6.5 MCP 协议集成

- MCP Server 以 stdio JSON-RPC 方式运行，暴露全部工具
- Claude Code CLI 可通过 MCP 协议直接调用平台工具
- ClaudeCodeRunner 支持 one-shot 和 daemon 两种模式

## 八、技术特性

### 性能优化
- 多论文并行分析（ThreadPoolExecutor，max_workers=4）
- PDF 解析早期退出（质量 > 0.6 不再尝试后续策略）
- 代码分块结果缓存（JSON 存储）

- API 层路径穿越防护（`abspath` 校验）
- ZIP 文件路径遍历攻击拦截

- 文件保存前自动备份（`.bak`）
- 文件上传大小和类型校验

### 错误处理
- 统一错误日志系统（`~/.research-copilot-os/logs/`）
- 全端点 traceback 打印
- 前端 monkey-patch 拦截 DeltaGenerator 泄露
- 安全的字符串转换（`clean_latex` + `safe_str`）

### 前端特性
- Streamlit 深色主题
- 4 模块顶部导航栏
- 文件拖拽上传（虚线边框视觉提示）
- LaTeX 公式渲染（`\[...\]` → `$$...$$` 自动转换）
- 侧边栏 AI 助手固定入口
