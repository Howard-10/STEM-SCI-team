# 物理 STEM 知识库：首批 50 篇文献审核清单

## 使用说明

这是一份用于建立 STEM-SCI 专题知识库的**首轮候选语料审核稿**。主题范围是“物理 STEM 教育、AI/数字技术、计算建模、项目式学习、师范生培养与学习评价”。

- 全部 50 篇 PDF 已从 AIMS Press 的官方开放获取页面下载到本机 `data/local/literature_pdfs/`；该目录及其 SHA256 清单均被 Git 忽略，不会被提交或推送。
- 每篇的 DOI、官方落地页、下载 URL、文件大小、SHA256 都保存于本机 `data/local/literature_manifest.json`。
- 下列“概要”是根据论文题目、官方摘要和元数据写成的**入库前导读**，不是对论文结论的替代；正式引用前必须由人工阅读全文、核对方法与页码。
- 本批是可用的 AIMS 开放获取语料。原计划中的 Springer *International Journal of STEM Education* 候选论文因出版商的浏览器挑战页暂未能自动下载；它们不计入本表的“已下载 50 篇”，后续应通过正常浏览器逐篇补齐。

审核标记建议：`保留-核心`、`保留-支撑`、`保留-外围`、`暂缓`、`剔除`。目前的建议只是初筛，不是最终决定。

## 建议的审核顺序

先由组员共同审核 ID `01–11`、`13–14`、`18`、`21`、`29`、`34–35`、`40`、`43–44`。这 22 篇最贴近“物理 STEM × AI 支架 × 编程/建模 × 师范生”的主线；通过后再决定其余材料是进入支撑库、外围库还是暂缓。

下一轮应补齐 Springer 的三类文献：

1. 物理实证干预（例如电路 STEM 研究）；
2. 编程学习与自我调节支架；
3. STEM 教育研究设计、量规、学习分析与师范生发展。

在录入 STEM-SCI 时，所有正式引用先设为 `source_verified`，不要将任何自动摘要或未人工核对的内容标记为 `human_verified`。
