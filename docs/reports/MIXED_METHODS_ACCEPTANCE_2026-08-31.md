# STEM-SCI Mixed Methods 验收记录（2026-08-31）

## 验收范围

本次验收针对“定量/实验结果 + 定性教师实施访谈”的混合方法入口，检查项目级路线、双 workstream、证据 Gate、研究问题 Gate 和右侧工作线展示。

测试主题：

> 用混合方法研究 Python 教学对学生计算思维表现的影响，并访谈教师了解实施过程和专业学习需求。

## 已验证结果

1. 主题自动判定为 `MIXED_METHODS`。
2. 控制面创建两条独立工作线：
   - `QUALITATIVE`：定性研究线
   - `EXPERIMENTAL`：定量/实验研究线
3. 两条工作线各自拥有步骤、阶段、Artifact、Gate 和当前动作。
4. 首次主题输入后，系统自动完成文献整理、混合检索、RRF 融合和重排序。
5. 证据阶段没有生成论文草稿，流程在证据充分性 Gate 停止。
6. 用户批准证据包后，定性工作线进入研究问题设计 Gate。
7. 右侧研究工作区显示当前工作线和等待中的另一条工作线。
8. 控制面契约测试验证：一条工作线完成后自动切换到下一条，只有全部工作线完成后项目才变为 `COMPLETED`。
