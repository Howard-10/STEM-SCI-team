## 已证实的质量结论

1. 文献 PDF 可以生成高质量、证据受限的**研究方案论文**，见 `ACCEPTANCE_MANUSCRIPT_2026-08-30.md`。新版方案将来源研究的理论、资料收集和编码程序与本项目的待收集资料严格区分，并给出抽样矩阵、访谈提纲、反例检查、同行审计和数据治理步骤。
2. 定性实证稿只有在上传去标识化访谈/问卷资料后才会生成主题候选；没有资料时工作流被阻断。
3. 量化 CSV 验收从导入至结果型论文草稿已通过端到端测试。任何该测试的数值都必须标记为受控测试，不能写入用户研究结论。
4. 最终独立审稿已经支持项目成员 `reviewer` 角色；仍需要真实的 reviewer 身份和真实研究资料，这是科研治理约束，而非软件故障。
5. 受控量化稿单独生成研究问题、方法和分析计划；它只报告 `group` 与 `transfer_score` 的冻结样本比较，并明确不建立因果解释。
6. 论文候选的原子主张现在会持久化，并可通过 `GET /api/v1/projects/{project_id}/claims` 被审稿 Gate 和右侧可视化读取；主张记录本身不等于已通过人工审稿。
7. 未经网络实测确认的 Codex 配置不会再阻塞分析：它会直接使用同一批准规格和冻结数据的确定性 Python 模板，并记录 `CODEX_GENERATION_UNCONFIRMED`。即使未来已确认的 Codex 连接失效，调用也被限制在 5--120 秒（默认 20 秒）后再回退。
8. 研究者摘要是候选产物的可选增强，不再参与控制面阻塞：外部 LLM 最多尝试一次，默认 8 秒超时后保留保守的确定性摘要。
9. 主界面已收敛为对话驱动：首次主题会先自动进入路线判定和证据准备，连续完成内部检索、融合和候选生成后才在证据充分性 Gate 暂停；右侧仅展示内部进度、产物与正式 Gate，不要求研究者选择 Agent、勾选任务或批准调用计划。进度板在没有 Gate 时只会聚焦对话输入框，不会绕过编排器改变状态。
