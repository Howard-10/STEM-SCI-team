# STEM-SCI 效果验证报告模板

## 1. 验证目的

验证 STEM-SCI 是否能在研究者主导的前提下，降低 STEM 教育研究中的文献整理、研究设计和分析准备成本，同时保持引用、数据和研究结论的可追溯性。

## 4. 对照基线

至少记录一种可复核基线：人工检索、通用 Qwen 对话或现有科研工具。基线的输入、模型版本、提示和时间必须保存，不能只比较最终截图。

## 5. 结果解释规则

- Gold Set 未完成双人标注时，不报告 Recall、MRR 或 nDCG。
- 只有来源已核验且页码/字符位置可回链的材料，才计入正式引用正确率。
- 用户满意度不能替代学科正确性和引用核验。
- 试用结果只能说明本次用户和案例范围内的效果，不能外推到所有高校或学科。

## 7. 结论

用“在本次案例和用户范围内观察到……”描述结论。不得写成“系统已经证明能够提高学习成绩”或“可以替代研究者”。
