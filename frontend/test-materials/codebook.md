# sphere_fci_quantitative 字段说明

| 字段 | 含义 | 类型 | 测试说明 |
| --- | --- | --- | --- |
| `STUDID` | 去标识化学生编号 | 文本 | 只用于记录唯一性，不对应真实身份 |
| `GDR` | 性别编码 | 数值 | 用于检查分类变量和分组字段 |
| `AGE` | 年龄组编码 | 数值 | 用于检查范围和缺失值 |
| `FATHEDU` | 父亲教育程度编码 | 数值 | 背景变量 |
| `MOTHEDU` | 母亲教育程度编码 | 数值 | 背景变量 |
| `SCH` | 学校或教育背景编码 | 数值 | 背景变量 |
| `COH` | 队列或班级编码 | 数值 | 分层信息 |
| `group` | 分组标识 | 文本 | 测试中为 `gender_1` 和 `gender_2` |
| `transfer_score` | 电路迁移任务得分 | 数值 | 用于描述性分组比较 |
| `fci_percent` | FCI 百分比成绩 | 数值 | 用于结果卡片和图表展示 |

## 使用边界

本文件只服务于前端和后端流程验证。字段编码的实际教育学含义需要结合真实研究方案确认，不能仅凭编码直接推断因果关系。
