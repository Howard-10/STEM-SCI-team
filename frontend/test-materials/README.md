# STEM-SCI 前端完整测试资料

这份资料用于在本地前端完成一次可复现的真实用户流程测试。测试对象是物理 STEM 电路教学研究，覆盖对话、知识库、研究方案、证据、数据审计、分析代码、论文产出和最终审查。

## 资料清单

| 文件 | 用途 |
| --- | --- |
| `Baptista2023_STEM_Electric_Circuits.pdf` | 原始物理 STEM 论文，用于上传、证据定位和对话引用 |
| `sphere_fci_quantitative.csv` | 去标识化样例数据，用于数据登记、字段审查、冻结和统计结果展示 |
| `codebook.md` | CSV 字段说明、变量类型和测试边界 |
| `dialogue-prompts.md` | 多类型对话问题，覆盖概括、证据边界、研究设计、数据解释、结果写作和风险追问 |
| `frontend-flow-checklist.md` | 前端逐步验收清单，记录每一步应看到的内容和按钮 |

## 建议测试顺序

1. 登录本地账号，进入已有物理 STEM 项目。
2. 在知识库上传 `Baptista2023_STEM_Electric_Circuits.pdf`。
3. 在对话区依次发送 `dialogue-prompts.md` 中的问题。
4. 打开左侧“产出工作区”，检查六个产出分区。
5. 分别打开研究方案、证据、数据、代码、论文和最终审查工作台。
6. 上传 `sphere_fci_quantitative.csv`，完成数据审计后再进行冻结或分析确认。
7. 对候选论文、代码和证据执行人工审核，确认版本是否进入知识库。

## 测试边界

- 论文用于验证来源识别、摘要、证据片段和引用定位，不代表本项目已有实证结论。
- CSV 是前端流程测试数据，所有结果应标注为描述性或测试性结果。
- 不应把候选论文、候选代码或候选证据直接当作正式研究结论。
- 每次人工确认后，应能在知识库中看到对应的版本、状态和来源链。

## 预期结果

完成测试后，前端应能清楚显示：

- 对话消息、轮次和本轮依据；
- 当前项目资料和长期研究资产；
- 六类产出卡片及其数量、状态和入口；
- 专用工作台中的可编辑内容、审核信息和版本边界；
- 论文、数据、代码、证据和主张之间的关联关系。
