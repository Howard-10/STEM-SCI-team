# 前端完整流程验收清单

## A. 进入项目

- [ ] 登录后能看到用户名和当前项目。
- [ ] 左侧“研究对话”“产出工作区”“知识库”三个入口均可点击。
- [ ] 后端状态显示在线或给出明确的离线提示。

## B. 研究对话

- [ ] 研究信息展开时显示概览、研究进度和对话。
- [ ] 研究信息收起时仍显示“研究对话”、历史消息和发送栏。
- [ ] 消息区可以独立滚动，输入框位于第二窗口底部。
- [ ] 对话消息中的依据卡片可以打开来源定位。
- [ ] 发送问题后轮次、消息和研究状态会更新。

## C. 知识库

- [ ] 可以上传 PDF 或 DOCX。
- [ ] 当前项目资料区域可以独立滚动。
- [ ] 原始来源、候选论文、审核后论文、证据包、主张绑定和数据审计分区可展开。
- [ ] 长期资产中能看到论文、候选产物、正式证据和版本状态。

## D. 产出工作区

- [ ] 六个分区以三列两行卡片显示。
- [ ] 卡片显示类别标识、产出数量、摘要和进入工作台的按钮。
- [ ] 卡片带有轻量边框、颜色区分和悬停状态，不遮挡文字。
- [ ] 点击卡片后进入对应专用工作台。
- [ ] 工作台可以返回产出目录，不影响当前对话。

## E. 六类专用工作台

- [ ] 研究问题与方案：能看到研究问题、变量、设计、样本与分组及审核状态。
- [ ] 证据与文献：能看到来源、DOI、页码、文本片段和人工确认入口。
- [ ] 数据与审计：能上传 CSV，查看字段、缺失、重复、异常和冻结信息。
- [ ] 分析与代码：能看到代码候选、代码编辑区、校验结果和统一通过入口。
- [ ] 论文产出：能查看候选正文、版本、主张绑定和投稿格式化 / LaTeX 入口。
- [ ] 最终审查：能展开查看证据、引用、结果、数据和结论边界。

## F. 测试结论记录

测试完成后记录以下内容：

- 流程是否从登录、上传、对话、产出、审核连通到知识库；
- 每个接口返回是否能在前端找到对应的内容位置；
- 候选产物是否明确标注状态，是否需要人工确认；
- 论文、证据、数据和代码是否保留版本与来源链；
- 发现的问题、复现步骤和修复结果。
